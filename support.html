Common questions

Does my focus timer keep running if I leave the app?

Yes. The timer is based on timestamps, so it stays accurate when the app is in the background or closed. Allow notifications to hear when a session ends.

Where is my data stored?

Everything stays on your device. There is no account and nothing is uploaded. See the privacy policy.

How do I back up my history?

Open You → Backups, export and privacy to save a backup file with the system share sheet. You can restore that file from the same screen on a new device.

How do I restore or cancel Habitat Plus?

Open You → Habitat Plus and tap Restore purchases. To cancel, go to iOS Settings → your name → Subscriptions → Focus Habitat. Cancelling never removes anything you have already earned.

Live Activity is not showing

Check iOS Settings → Focus Habitat → Live Activities is on, then start a new focus session.
